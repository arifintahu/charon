## Config change applied 2026-06-10

**Consecutive-SL circuit breaker** — pauses new degen entries for 60 min after 3 consecutive SL exits.

**Why:** the strategy's edge is thin on calm days (~+1–3% avg/trade, ~50% win rate). The dominant risk is regime days (market-wide dump): on Jun 07 the bot continued opening positions into a sustained dump, taking 7 consecutive SLs in one cluster (21:00–23:00 WIB), with fills averaging −49% in some mcap bands. No entry filter can screen for a regime shift already in progress. A time-based pause after a streak of fast SLs cuts exposure during the acute phase.

**What to watch next (3d window from 2026-06-10):**
- Pause frequency: how often the breaker fires on normal days. Should be rare; if it fires daily, reduce `sl_streak_cooldown_count` threshold or widen `sl_streak_cooldown_ms`.
- Winners missed during pauses: the trade-off is real — Jun 08 had 53.7% SL share but finished positive; a strict breaker would have suppressed some of that. Monitor TRAILING_TP count vs prior windows.
- Net PnL: the breaker adds no value if crash-day loss reduction is offset by winners skipped on normal days.

function checkSlCooldown(stratId) {
  const key = `sl_cooldown_until_${stratId}`;
  if (Date.now() < numSetting(key, 0)) return true;
  const threshold = numSetting('sl_streak_cooldown_count', 3);
  const recent = recentClosedExits(stratId, threshold);
  if (recent.length >= threshold && recent.every(p => p.exit_reason === 'SL')) {
    setSetting(key, String(Date.now() + numSetting('sl_streak_cooldown_ms', 3600000)));
    return true;
  }
  return false;
}
