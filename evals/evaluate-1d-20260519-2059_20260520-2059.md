## Code changes applied — 2026-05-20

Applied in response to rec 2 (post-entry SL cooldown). The 2.6 min avg SL hold and bimodal PnL distribution indicate the bot frequently catches micro-pump tops and is immediately stopped out before price can recover. A 30-second window before SL arms gives entries room to absorb normal tick volatility.

### New field: `sl_arm_delay_ms`

SL is suppressed for the first `sl_arm_delay_ms` milliseconds after position open. TP and trailing arm are unaffected — if price runs immediately, the trail arms and locks gains normally. Only the downside exit is delayed.

Set to `30000` (30s) on `degen`. Set to `0` on all other strategies (no behavior change).
